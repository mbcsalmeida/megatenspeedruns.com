## About

### Shin Megami Tensei: Strange Journey

There isn't much to report on SMT:SJ as most runs were done by the japanese megaten speedrunning community. In 2025, runner [Jonperi23](https://www.twitch.tv/jonperi23) picked up the run and created the first accessible notes in english for the Chaos route, opening the door for more runners to try out this challenging run.

We are aware of manipping possibilities for this game, but no runs have been completed, as far as we know, that utilize any manipulation.

### Shin Megami Tensei: Strange Journey Redux

The Redux speedrun utilizes manipulation for recruitments.
